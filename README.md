# Cutlist

A video editor built around Remotion projects: a timeline, a live preview and export.

## Install

**Mac**: open **Terminal** (Cmd+Space, type Terminal), paste this line and press Return:

```bash
curl -fsSL https://github.com/atmujtababaig/cutlist-app/releases/latest/download/install-mac.sh | bash
```

**Windows**: open **PowerShell** (Start menu, type PowerShell), paste this line and press Enter:

```powershell
irm https://github.com/atmujtababaig/cutlist-app/releases/latest/download/install-windows.ps1 | iex
```

Or download [Install-Cutlist.bat](https://github.com/atmujtababaig/cutlist-app/releases/latest/download/Install-Cutlist.bat) and double-click it
(if Windows says it protected your PC: **More info**, then **Run anyway**).

The installer asks where to put Cutlist and whether to add Find clips and captions (a bigger
download, about 750 MB, optional). Nothing is installed outside that folder, and no password or
admin rights are asked. When it is done, Cutlist opens.

## After that

- Open Cutlist from the **Dock** (Mac) or the **Desktop / Start menu** icon (Windows).
- It **updates itself**: a newer version is installed the next time you open it.
- Something broken? Run the same line again; your projects and sign-ins are kept.
- Remove it: delete the Cutlist folder (Mac: ~/Applications/Cutlist, Windows:
  %LOCALAPPDATA%\Programs\Cutlist) and its icons.
